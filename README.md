Bingo Master Board helps you host and manage your own Bingo games.
* Randomly draw and project Bingo balls
* Display the count of balls drawn/remaining
* Set a winning pattern
* Change the look of the board with themes
* Manually select balls if you're drawing physical balls in person

Bingo Master Board is designed for full screen view in the browser.

Bingo Master Board supports the latest versions of Edge, Firefox, Chrome, __Internet Explorer is not supported.__
